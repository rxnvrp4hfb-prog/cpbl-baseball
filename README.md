`https://api.leokuo.com/cpbl/...`

## GitHub Pages

將此資料夾內容直接放在 `cpbl-baseball` repository 根目錄：

- `index.html`
- `CNAME`
- `README.md`

GitHub → Settings → Pages：

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/(root)`

Custom domain: `baseball.leokuo.com`
